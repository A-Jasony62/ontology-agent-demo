- API 支持 `POST /api/ontology/reload`、MCP 支持 SIGHUP 触发重载，修改定义后**无需重启进程**；

- `/api/health` 扩展版本/dirty/变更留痕信息。

## 3. 关键设计

### D-P2-1 API reload（REQ-01.1）

```
POST /api/ontology/reload -> {status, loaded, triples, individuals, elapsed_ms}
   1. 构造新引擎实例（核心 + extensions 重 parse + 推理）——失败则 400 + 旧状态继续
   2. 成功 → 原子替换模块级 ENGINE / 重建 ADAPTER（load_domain）
   3. 返回加载摘要
```

- 参考现有 `load_ontology` 的 `global ENGINE` 替换模式（`api/main.py:174-196`）；
- **原子性**：新实例验证通过后才替换引用，替换前的在途查询不受影响（Python 全局引用切换即原子）。

### D-P2-2 MCP SIGHUP（REQ-01.2）——工具闭包动态解析

**问题**：现有 `register_tools` 闭包捕获 adapter 实例（`domains/agent_task/mcp.py:16-45`），换引擎后闭包仍指旧对象。

**改造**：工具闭包不再绑定实例，改为绑定"**动态获取当前 adapter 的工厂**"：

```python
# domains/agent_task/mcp.py
def register_tools(server, get_adapter):          # 签名变更：传工厂而非实例
    @server.tool(description="能力匹配（R1/R2）：...")
    def capability_match(task: str) -> dict:
        return get_adapter().capability_match(get_adapter().NS[task])
```

```python
# mcp/mcp_server.py main()
state = {"engine": ..., "adapter": ...}
def get_adapter(): return state["adapter"]
build_server(engine, get_adapter, ...)            # 闭包只依赖 get_adapter

def _on_sighup(signum, frame):
    new_engine = OntologyEngine(onto_path, extensions_dir=...)  # 重建（失败则 log，保持旧）
    state["engine"], state["adapter"] = new_engine, load_domain(domain, new_engine)
```

SIGHUP 只需替换 `state` 引用，工具调用时动态取到新 adapter——**无需重建 MCPServer、无监听中断**。

### D-P2-3 单一写入者约定（REQ-02）

- **写入入口**：API（classify/delete/revoke/import）为正式变更入口；
- **MCP 端写工具（classify/assign）保持可用**（本地单机场景），但 REQ-02 约定**正式变更走 API**；文档固化约定，不做硬限制（避免破坏现有调用方）；
- 变更统一记录 changelog（批次一已建），两端可查询。
- `GET /api/ontology/status`：返回两端一致性——
  - API 端：本体文件哈希 + 内存哈希 + dirty 标记；
  - MCP 端：由 CLI（批次三）探测，或 MCP 增加只读 `status` 工具（返回其内存哈希）；
  - 一致性 = 两端"基线文件哈希 + 内存变更计数"相同。

### D-P2-4 health 扩展（REQ-03）

```
GET /api/health 增加：
  version: 本体 versionInfo（未配置时为文件 mtime）
  loaded_at / load_elapsed_ms
  dirty: bool（存在未 commit 变更）
  pending_changes: int（changelog 未提交数）
  changelog: [{time, op, operator, detail}]（最近 5 条）
  counts: agents/tasks/capabilities/constraints/assignments/inferred_triples
```
