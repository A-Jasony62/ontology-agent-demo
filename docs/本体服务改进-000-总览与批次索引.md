## 3. 统一约定（全系列适用）

- **依据**：《本体服务改进需求说明书》（REQ-01~09）与《本体服务改进需求评审意见》（BLOCK-1 / MUST-1~5 / S-1~6）；
- **范围**：仅功能层面改造，不改变本体语义、推理规则（R1–R4）与领域模型；
- **兼容性**：所有新增参数默认值保持现有行为（`persist=false` 等），不破坏现有调用方；
- **操作留痕**：破坏性操作（delete / rollback / import）记录操作者+时间；
- **服务重启**：先 `for p in 8000 9000; do lsof -ti tcp:$p | xargs kill -9; done`，再 nohup 启动（API :8000 / MCP :9000）；
- **当前基线**：v0.1.0，pytest 29 项全绿；MCP 14 工具注册冒烟通过；API 健康检查 200。
